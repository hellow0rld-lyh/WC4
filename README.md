# 修改内容

本项目在原版基础上进行了以下功能扩展与机制调整。

## 功能扩展

* 将局内资源上限扩展至 `999999`
* 将基础将领槽位上限扩展至 `512`
* 将兑换码功能改为本地运行
* 将兑换码长度上限扩展至 `22` 位
* 实现原生 `15` 技能槽支持
* 新增“锁定三星并一键胜利”功能

## 技能与战斗机制调整

* 移除“巨炮”增益效果的伤害上限
* 修改“爆破”技能，使其可以对空军单位生效
* 新增技能 `type`，作为空军通用增伤类型
* 修改所有“半血以上增伤”类技能的触发判定，统一调整为当前血量大于 `50%` 时生效

## 内容补充

* 新增征服模式介绍
* 新增将领介绍
* 新增兵种介绍

## AI 行为调整

* 解除默认 AI 对“战略核威慑”（`Type 81`）的使用限制
* 敌方 AI、盟友 AI 与玩家自动托管 AI 均可使用战略核威慑
* 修复 AI 激活战略核威慑后重复触发技能、无法继续选择攻击目标的问题
* 激活战略核威慑后，复用白杨导弹车原有的“导弹攻击”（`Type 82`）目标选择与攻击流程
* 核心流程已经过实机验证，AI 可以正常完成技能激活、目标选择与后续核打击


## 2026-07-13 更新：多个人控国家支持预览

原版大量玩家操作会固定读取“第一个人控国家”，导致第二、第三个人控国家虽然能够进入回合，却可能出现攻击无伤害、资源扣错国家、生产和技能提交失败、界面仍显示第一个国家等问题。

本预览版将已经确认属于“当前操作国家”的路径改为读取当前回合国家，并为征服模式增加精简的多个人控胜负校正。

### 已修复范围

#### 手动战斗动作

- 普通攻击；
- 移动及其他通用手动动作提交；
- 空军、导弹、核武等共用动作路径；
- 动作执行国家由第一个人控国家改为当前回合国家。

#### 生产与建设

- 普通部队生产；
- 空军、导弹和核武生产；
- 精英部队生产与增援；
- 防御设施建造；
- 城市设施升级；
- 城市特性和城市操作界面；
- 设施升级后的界面刷新。

#### 特殊主动技能

- 第一主动技能槽；
- 第二主动技能槽；
- 多目标技能确认提交；
- 技能目标、CD、状态和效果执行器保持原版。

#### 卫星、国家科技与移动后处理

- 卫星执行；
- 卫星按钮状态、等级和冷却显示；
- 国家科技界面入口；
- 所有人控国家的移动完成后选区清理；
- AI 移动路径保持原版。

#### 战斗 HUD

- 战斗界面初始化；
- 当前国家国旗；
- 资源栏；
- 当前操作阵营刷新；
- 传奇部队相关按钮状态。

#### 外交

- 外交入口；
- 协议、援助和宣战；
- 进入战争流程；
- 诱降及其他外交操作界面；
- 外交目标国家和关系公式没有修改。

#### 新回合与事件展示

- 新回合收入；
- 将领数量显示；
- 玩家回合事件入口；
- 征服事件展示所使用的国家；
- 核心事件条件仍保持原版。

#### 征服模式胜负

仅在 `BattleMode == 2` 的征服模式追加多个人控校正：

- 所有人控国家均失败后才判整局失败；
- 第一个人控国家出局、其他人控国家仍有效时，不再立即结束整局；
- 只剩一个有效非中立阵营，且该阵营包含存活的人控国家时判胜；
- 评分、统计、成就、奖励和结算界面仍使用原版逻辑。

## 已知限制

1. 当前胜负校正只作用于征服模式，集团军 `BattleMode == 10` 仍使用原版结算。
2. 征服评分、击杀统计、城市统计、成就、奖励和结算 UI 没有做多国汇总。
3. 结算界面仍可能显示第一个人控国家的旗帜、名称或成绩。
4. 敌对人控国家可以继续互相作战，但整局只有一套全局胜负标志，不能为每个国家分别显示胜负。
5. 核心事件条件没有全局替换，因为其中混合了主玩家、任意人控、事件指定国和阵营条件。
6. 本包为未签名 Pre-release。已经在当前测试设备通过 ADB 覆盖安装，但普通系统安装器和其他设备兼容性不保证。

## 安装

安装前建议备份存档。

保留现有数据的覆盖安装方式：

```bash
adb install -r wc4_multi_player_minimal_outcome_aligned.apk
```

不要为了升级而先卸载应用，否则可能清除游戏数据。

如果系统拒绝安装，请确认：

- 设备支持 `arm64-v8a`；
- 已连接 ADB；
- 现有安装包与测试包的安装策略兼容；
- 没有使用仅支持 32 位 ABI 的设备。
