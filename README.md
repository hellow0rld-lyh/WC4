# 修改内容

本项目在原版基础上进行了以下功能扩展与机制调整。

## 功能扩展

* 将局内资源上限扩展至 `999999`
* 将基础将领槽位上限扩展至 `512`
* 将兑换码功能改为本地运行
* 将兑换码长度上限扩展至 `22` 位
* 实现原生 `15` 技能槽支持
* 新增“锁定三星并一键胜利”功能

## 技能与战斗机制调整

* 移除“巨炮”增益效果的伤害上限
* 修改“爆破”技能，使其可以对空军单位生效
* 新增技能 `type`，作为空军通用增伤类型
* 修改所有“半血以上增伤”类技能的触发判定，统一调整为当前血量大于 `50%` 时生效

## 内容补充

* 新增征服模式介绍
* 新增将领介绍
* 新增兵种介绍

## AI 行为调整

* 解除默认 AI 对“战略核威慑”（`Type 81`）的使用限制
* 敌方 AI、盟友 AI 与玩家自动托管 AI 均可使用战略核威慑
* 修复 AI 激活战略核威慑后重复触发技能、无法继续选择攻击目标的问题
* 激活战略核威慑后，复用白杨导弹车原有的“导弹攻击”（`Type 82`）目标选择与攻击流程
* 核心流程已经过实机验证，AI 可以正常完成技能激活、目标选择与后续核打击
